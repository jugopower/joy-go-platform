## 圖片檔名

- hero.jpg
- teacher.jpg
- news1.jpg、news2.jpg、news3.jpg
- gallery1.jpg、gallery2.jpg、gallery3.jpg、gallery4.jpg

## Render 部署
1. 解壓縮並將全部檔案上傳 GitHub。
2. Render 選 New → Static Site。
3. 連接 Repository。
4. Build Command 留空。
5. Publish Directory 填入 `.`。
