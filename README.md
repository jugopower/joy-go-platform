## 上傳方式
解壓縮後，將以下檔案上傳到 GitHub joy-go-platform 並覆蓋舊檔：
- index.html
- styles.css
- script.js
- README.md
- render.yaml

按 Commit changes 後，到 Render：
Manual Deploy → Deploy latest commit
