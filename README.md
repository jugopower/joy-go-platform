# Joy Go Platform Build 010.3

## 核心修正
- 聯絡按鈕改用瀏覽器原生 details/summary
- 完全取消 JavaScript 控制，避免舊版事件互相衝突
- iPad Safari 點「聯絡」即可直接展開電話與 LINE
- 再點「聯絡」即可收合
- 保留報名表附近自動往上移功能
- 版本更新為 Build 010.3

- index.html
- styles.css
- script.js
- README.md
- render.yaml
- .nojekyll
