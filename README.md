## 上傳 GitHub
在現有 Repository 內：
1. Add file → Upload files
2. 上傳以下檔案並覆蓋舊檔：
   - index.html
   - styles.css
   - script.js
   - README.md
   - render.yaml
   - .nojekyll
3. 按 Commit changes
4. GitHub Pages 會自動重新部署

## 加入朱老師照片
之後只要另外上傳一張照片到 Repository 根目錄：
- 檔名必須是 `teacher.jpg`

網站就會自動顯示照片，不需要修改程式。
